# LICENCE-NOTES.md — Azure architecture icons

**Sets vendored:**

| Set | Version | Source |
|---|---|---|
| Azure architecture icons | `Azure_Public_Service_Icons_V24` (July 2026 update) | https://learn.microsoft.com/en-us/azure/architecture/icons/ |
| Microsoft Entra architecture icons | October 2023 pack (colour SVGs) | https://learn.microsoft.com/en-us/entra/architecture/architecture-icons |

**Vendored into:** `icons/` (category folders as downloaded, `icons/entra pack/`
for the Entra colour icons, plus flat `icons/<slug>.svg` copies generated by
`bin/build_manifest.py`).
**Vendored on:** 2026-07-19 (update this line when the set is refreshed).

## Permitted use (as stated by Microsoft on the download page)

- The icons may be used **in architecture diagrams, training materials, and
  documentation** that describe Microsoft Azure.
- Icons must **not be recoloured, distorted, rotated, cropped, or otherwise
  altered**. This toolkit copies the SVGs byte-for-byte and only scales them
  uniformly (`svc` class, fixed square dimensions) — never restyled inline.
- Icons must **not be used to represent your own product or service**, nor in a
  way that implies Microsoft endorsement.
- Microsoft **trademarks and logos** are governed separately by Microsoft's
  Trademark and Brand Guidelines; the icon licence does not grant trademark
  rights.

## How this repository stays compliant

| Rule | Enforced by |
|---|---|
| No recolouring / distortion | `styles/azure.d2` restricts leaf nodes to `shape: image` with fixed square size; the style contract forbids inline node styles |
| Unmodified files | `bin/build_manifest.py` uses `shutil.copyfile` — no SVG rewriting |
| Official icons only | `skill/icon-index.md` + `icons/manifest.json` are the closed vocabulary the generator may draw from |
| Provenance recorded | `icons/manifest.json` records the original official filename for every slug |

## Refreshing the set

1. Download the current ZIP from the link above.
2. Replace the category folders under `icons/` (keep the folder names).
3. Run `python bin/build_manifest.py` and fix any unresolved slugs it reports.
4. Update the *Vendored on* date above.

## Note on the Entra pack

The plain **Microsoft Entra ID** tenant icon is not part of the Azure
architecture icon set, so the Entra pack is vendored alongside it and supplies
the `entra`, `entragovernance`, and `entraworkloadid` slugs. The Entra terms add
one restriction beyond the Azure terms: **do not use the icons in marketing
communications**.
