# icon-index.md — the only icons the LLM may use

Write icons as `icon: ./icons/<slug>.svg`. Paths are resolved from the
**repository root** (the render scripts always run `d2` from there), so this
form is correct no matter where the `.d2` file lives.

Every slug below resolves to an official Microsoft Azure SVG. The machine
-readable version is `icons/manifest.json`, generated by
`python bin/build_manifest.py` — it records the original official filename for
each slug. **Never invent a slug.** If a service is missing, pick the closest,
leave a `# TODO: icon <name>` comment, and tell the maintainer to add it to
`VOCAB` in `bin/build_manifest.py`.

## Notes for the maintainer
- Add a service by adding one line to `VOCAB` in `bin/build_manifest.py`
  (`slug: (aliases, official-filename match terms)`), re-running the script, and
  adding the row here. The script fails loudly on any slug it cannot resolve.
- The slug scheme is the stable contract: `.d2` sources depend on it. Rename a
  slug only with a repo-wide search-and-replace.
- Icons are copied unmodified; see `LICENCE-NOTES.md` for the permitted-use terms.
